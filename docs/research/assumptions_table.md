## Как отслеживаем изменение статуса

**Гипотеза → источник → исследование → фактический результат → решение.** Допустимые статусы: «проверить», «подтверждено наблюдением», «частично подтверждено», «опровергнуто», «зафиксировано как бизнес-требование без пользовательского измерения», «отложено».

Статус «проблема сообщена организатором» не равен «решение проверено пилотом» и не равен «подтверждено опросом». Статус «зафиксировано как требование» не равен «подтверждено опросом». Если реальный опрос выявит слабый спрос на историю результатов, это должно изменить порядок пользовательских функций, а не быть скрыто.
