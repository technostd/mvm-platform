# Регистрация на Московские веломарафоны: процесс «как есть» (As-Is)

> **Цель документа** — зафиксировать, как регистрация на МВМ устроена прямо сейчас и где возникают препятствия: со стороны участника и со стороны организаторов (management). Это снимок публично наблюдаемых процессов до внедрения собственной платформы — точка отсчёта для сравнения «как станет». **Внутренняя ручная работа, права на данные, частота ошибок и трудозатраты являются гипотезами до интервью/наблюдений.**
>
> Фактура: сайт [velomarathon.ru](https://velomarathon.ru) (состояние на сентябрь 2026), reg.place, материалы исследования. Детали, не видимые снаружи, помечены *(требует проверки интервью)*.

## 1. Экосистема МВМ сегодня: набор разрозненных сервисов

У серии нет единой платформы. Каждую функцию выполняет отдельный внешний сервис или ручной инструмент:

| Задача | Инструмент сейчас |
|---|---|
| Лицевой сайт серии | **Tilda**-лендинг velomarathon.ru: анонсы, карточки 7 этапов сезона 2026, немарафоны, кэмпы, история с 2020 г. |
| Положение серии | **Google Docs** (отдельный документ по ссылке) |
| Регистрация на этап | **reg.place** — на каждый этап своя страница-кампания (напр. `reg.place/events/7tomilinskiy-velomarathon-2026`) |
| Оплата | платёжный контур reg.place |
| Хронометраж/результаты | **results.velomarathon.ru**; исторически — results.zone и **sportident.online**, часть старых этапов — на **wixsite.com** |
| Фото | photo.velomarathon.ru (отдельный сервис) |
| Справки участников | отдельная страница `/spravki` на Tilda |
| Коммуникация | Telegram-канал **t.me/mtbmsk** (основной канал), VK, Instagram, почта **mtb@vsemsport.ru** |
| Запись на кэмпы | **личная переписка в Telegram** (t.me/mtb_training) — без формы и оплаты онлайн |
| Набор волонтёров в команду | всплывающая **Tilda-форма** на сайте |
| Мерч/сувениры | партнёрские магазины (напр. burlak.store); сувенир — часть стартового пакета; предзаказа мерча с заявкой нет |
| Презентация для партнёров | файл на **Яндекс.Диске** |

Организатор серии — компания «Всем спорт» (vsemsport.ru), основатель — Максим Капитонов. Юридически и коммуникационно МВМ живёт под брендом/почтой организатора, а не единой платформы.

## 2. Как участник регистрируется сегодня (путь)

1. **Узнать об этапе.** Анонс и обратный отсчёт — на Tilda-сайте и в Telegram `@mtbmsk`. Календарь серии есть, но это картинка-таблица на лендинге.
2. **Прочитать условия.** Положение серии — в Google Docs; детали допуска, дистанций, возвратов — на Tilda-странице этапа и в оферте reg.place. Три разных места для «правил игры».
3. **Перейти на reg.place по кнопке «Зарегистрироваться».** Каждый этап — отдельная кампания агрегатора: свой URL, своя форма, свои сроки.
4. **Завести аккаунт в reg.place.** Профиль (ФИО, контакты, документы) создаётся в чужом сервисе, не у МВМ.
5. **Заполнить анкету и оплатить.** Дистанция, категория, согласия; оплата — по правилам и тарифам reg.place.
6. **Отслеживать статус.** «Заявка подана / оплачена / допущена» видно только в личном кабинете reg.place. На сайте МВМ — ничего.
7. **Перед стартом.** Получение стартового пакета, номера, чипа хронометража на локации; сверка по выгрузке из reg.place *(процедура допуска требует проверки)*.
8. **Гонка.** Электронный хронометраж фиксирует время.
9. **Результаты.** Публикуются на results.velomarathon.ru отдельно от регистрации; связки «моя заявка → моё время → моё место» в одном месте нет.
10. **Вопросы (перенос, возврат, ошибка).** Только почта `mtb@vsemsport.ru` / Telegram и ручная работа организатора.
11. **Следующий этап — всё заново.** Шаги 1–6 повторяются для каждого старта серии; зимние немарафоны, летние немарафоны и кэмпы — каждый со своей механикой (у кэмпов — вообще запись через переписку в Telegram).

## 3. Препятствия на стороне участника

| # | Барьер | Где возникает |
|---|--------|---------------|
| U1 | Нет личного кабинета МВМ и единой истории заездов: 7 этапов сезона + немарафоны живут отдельными заявками в reg.place (гипотеза №1) | Весь путь |
| U2 | Регистрация = аккаунт в стороннем сервисе с чужим интерфейсом, в отрыве от бренда и сайта МВМ | Шаги 3–4 |
| U3 | Правила размазаны по трём местам: Tilda-страница этапа, Google Docs «Положение», оферта reg.place | Шаг 2 |
| U4 | Статус заявки/оплаты виден только в reg.place; с сайта МВМ — слепая зона | Шаг 6 |
| U5 | Нет self-service для возвратов и переносов: любой вопрос = письмо в `mtb@vsemsport.ru` и ожидание | Шаг 10 |
| U6 | Результат живёт отдельно от заявки: надо искать себя в протоколе на results.velomarathon.ru | Шаг 9 |
| U7 | Мерч нельзя купить вместе с заявкой — только партнёрский магазин или на месте (гипотеза №3) | Шаг 7 |
| U8 | Кэмпы оформляются ручной перепиской в Telegram — без онлайн-записи, оплаты и подтверждения | Кэмпы |
| U9 | Исторические результаты «рассыпаны» по четырём системам (results.velomarathon.ru / results.zone / sportident.online / wixsite) — история заездов до ~2023 недоступна из одного места | Шаги 9, 11 |

## 4. Препятствия на стороне управления (management)

| # | Барьер | Последствие |
|---|--------|-------------|
| M1 | Регистрационные данные обрабатываются в reg.place; объём прав на экспорт, хранение и повторное использование у организатора требует проверки | Возможны ограничения на сквозные сценарии; реальные договоры и права на данные не исследованы |
| M2 | Не подтверждён автоматический сквозной обмен «человек ↔ чип ↔ результат» между reg.place и хронометражем; возможна ручная сверка | Объём и частота ручной сверки подлежат замеру |
| M3 | Переносы/возвраты/вопросы могут обрабатываться вручную; их доля во времени команды не измерена | Масштабируемость организационной работы требует проверки на реальных трудозатратах |
| M4 | Контент и правила обслуживаются руками на Tilda: карточка этапа, положение в Google Docs, рассинхрон версий | Ошибки в допуске, типовые вопросы «а какие условия?» |
| M5 | Коммуникация фрагментирована: канал в Telegram, почта, списки в reg.place — сегментировать и таргетировать рассылки нечем | Обратная связь и допродажи — на глазок |
| M6 | Зависимость от тарифов, оферты и доступности чужих сервисов (reg.place, Tilda, Google) | Условия возврата диктует агрегатор; репутационные риски на МВМ |
| M7 | Запись на кэмпы через Telegram — заявки, оплаты и подтверждения ведёт человек в переписке | Потерянные заявки, отсутствие воронки и аналитики по кэмпам |
| M8 | Нет сквозной аналитики серии: конверсия заявки, возвратность, удержание между этапами не собираются | Решения по стратегии и партнёрским презентациям — без данных |
| M9 | Исторический архив результатов в 4 системах, часть — на стороннем wixsite | Теряется ценность «истории МВМ», которой серия гордится на сайте |

## 5. Итог

Регистрация на МВМ сегодня — **цепочка из 6+ разрозненных сервисов и ручной работы**: Tilda-сайт → Google Docs → reg.place → локация → results.velomarathon.ru → почта/Telegram.

- **Участник** не имеет ни единого кабинета, ни единой истории, ни прозрачного статуса — и проходит 5+ точек контакта на каждом этапе, повторяя их заново для каждого старта.
- **Организатор** зависит от обмена с внешней регистрацией; права на данные, объём ручной сверки с хронометражем и частота нестандартных случаев требуют интервью и замеров.

Именно барьеры U1–U9 и M1–M9 собственная платформа МВМ должна снять; перед проектированием To-Be их наличие и острота проверяются глубинными интервью (см. [таблицу предположений](assumptions_table.md) и [карту стейкхолдеров](stakeholders_map.md)).
