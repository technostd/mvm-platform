# Исследование проекта: Информационная платформа Московских веломарафонов

## О проекте
Разработка единой информационной платформы для организации, регистрации и управления серией московских веломарафонов. Проект направлен на создание независимого контура взаимодействия с участниками, отказ от сторонних агрегаторов и автоматизацию процессов тайминга и коммуникации.

## Цель исследования на данном этапе
Согласно методологии «Лаборатории исследования», мы переходим от абстрактных идей к проверке гипотез. На этом этапе необходимо:
1. Выявить ключевые предположения о потребностях пользователей.
2. Определить круг стейкхолдеров и их влияние на проект.
3. Подготовить вопросы для глубинных интервью.
